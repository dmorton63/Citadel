# Wallpaper Credits

This file tracks attribution for wallpapers shipped with Citadel.

Notes:
- CC0 / Public Domain: attribution not required, but allowed.
- CC-BY: attribution is required. Keep the license URL and source URL.
- If an image is modified (crop/resize/format conversion), note it.

## Format

- Season: <SPRING|SUMMER|AUTUMN|WINTER>
- File: <ramdisk/system/wall/*.PNG>
- Title: <title>
- Author: <name>
- Author URL: <url or blank>
- Source: <landing page url>
- License: <e.g. CC BY 4.0>
- License URL: <url>
- Changes: <e.g. cropped, resized to 975x645, converted to PNG>
