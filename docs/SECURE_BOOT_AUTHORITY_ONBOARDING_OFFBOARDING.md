# Secure Boot Authority Onboarding and Offboarding Checklist

## Onboarding Checklist

- [ ] Role assignment approved by domain owner
- [ ] Security training completed
- [ ] Least-privilege access provisioned
- [ ] Dual-control responsibilities acknowledged
- [ ] Runbook and escalation training completed
- [ ] Audit logging verification completed

## Offboarding Checklist

- [ ] Access revoked (signing systems, key tooling, CI gates)
- [ ] Escrow and approval privileges removed
- [ ] Active exceptions and tickets reassigned
- [ ] Audit review completed for prior 90 days of privileged activity
- [ ] Exit acknowledgment and handoff documented

## Change Control

Any onboarding/offboarding must include ticket linkage and owner sign-off.
