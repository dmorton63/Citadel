# Secure Boot Long-Term Maintenance Calendar

## Recurring Activities

### Monthly
- Fleet conformance scan and scorecard review
- Revocation freshness verification
- Exception register review

### Quarterly
- Key-expiry and drift deep review
- Recovery bundle validation drill
- Escrow access review
- Control self-assessment checklist completion

### Semi-Annual
- Signer compromise tabletop exercise
- Third-party firmware vetting process audit

### Annual
- Signing-service disaster recovery drill with measured objectives
- End-to-end Secure Boot program health review
- Policy and architecture record refresh

## Key Lifecycle Milestones
- Production signing key rotation: every 180 days or on incident
- Intermediate signer certificates: every 90 days
- Root policy review: annual minimum
